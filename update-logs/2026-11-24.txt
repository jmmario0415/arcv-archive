Arc-V 대진표 생성·공유 장애 수정
작업일: 2026-11-24 (한국 시간)

증상
- 만든 사람에게 보이는 대진표가 다른 사람에게 보이지 않음.

확인한 원인
- 기존 공개 MQTT 브로커에 접속과 구독은 성공했으나, 보관(retained) 메시지를 새 접속자에게 전달하지 않는 현상을 독립 접속으로 재현함.
- 이전 대진표 목록도 해당 브로커에서 새 접속자로 수신되지 않았음.

수정
- 대진표 메타 정보와 경기 결과를 기존 Supabase 프로젝트에 영구 저장하도록 변경.
- 새 테이블 duel_live 및 쓰기 RPC duel_live_write 추가. 기록실·멤버 데이터 유지.
- 서버 저장 확인 후 생성 완료. 연결 실패 시 생성 버튼 비활성화.
- 다른 접속자는 3초마다 서버의 목록과 경기 결과 갱신.
- 서로 다른 경기의 동시 저장은 경기별로 병합. 토너먼트 다음 라운드 초기화는 한 요청으로 처리.
- 폴링 내용이 같으면 입력 폼을 다시 만들지 않아 작성 중 포커스 유지.
- 이전 브라우저의 대진표 사본은 서버에 없는 경우만 복구. 최신 서버 결과는 덮어쓰지 않음.
- 삭제 표시는 서버에 남겨 오래된 브라우저 사본의 재등록 방지.
- 공개 MQTT 서버와 외부 MQTT 라이브러리 의존 제거.

검증
- verify-live-store.cjs: 별도 클라이언트 조회, 동시 저장, 변경 없는 폴링, 사본 복구, 삭제 후 복구 방지, 실패 및 재연결 처리 통과.
- 기존 기록실·멤버·대진표 통합·매치 스코어 검사 통과.
- 실제 Supabase에서 별도 클라이언트 생성/조회, 매치 점수, 동시 경기 저장, 점수 초기화 확인.
- 검증용 대회는 삭제 표시로 목록에서 정리함.

이용 안내
- 통합 대진표: https://jmmario0415.github.io/arcv-archive/duel/
- 기존 대진표를 만든 브라우저에서 통합 사이트를 다시 열면 남아 있는 사본을 복구할 수 있음.
- 모든 브라우저와 기존 서버에서 사라진 기록은 자동 복구할 원본이 없음.
- 이전 외부 사이트는 수정되지 않으며 통합 사이트와 동기화되지 않음.
